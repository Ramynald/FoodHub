# Идеи FoodHub

## Интерфейс

- [ ] Splash Screen с большим логотипом FoodHub.
- [ ] Плавное исчезновение заставки.
- [ ] Hero-блок «Рецепт дня».
- [ ] Переключатель языков.
- [ ] Темная тема.

## Дизайн

- [ ] Использовать компактный логотип в хедере.
- [ ] Использовать большой логотип как заставку.
- [ ] Использовать разные версии логотипа для светлой и темной темы.

## Будущее

- [ ] Telegram-бот.
- [ ] AI-помощник.
- [ ] Планировщик питания.
- [ ] Умные рекомендации рецептов.
