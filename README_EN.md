# 🍳 FoodHub

FoodHub is a modern platform for publishing, discovering, and managing recipes.

The project is based on the educational Foodgram project but is now evolving into an independent product with new features and its own vision.

---

## ✨ Current Features

The project currently includes:

- User authentication
- Recipe publishing
- Favorites
- Shopping cart
- Ingredients and tags
- Image uploads
- REST API

---

## 🚀 Getting Started

### Requirements

- Docker
- Docker Compose

### Clone the repository

```bash
git clone https://github.com/Ramynald/FoodHub.git
cd FoodHub
```

### Configure environment variables

Create a `.env` file and configure the required environment variables.

### Run the project

```bash
docker compose up --build
```

The application will be available at:

- Frontend — http://localhost/
- API — http://localhost/api/
- Admin panel — http://localhost/admin/
