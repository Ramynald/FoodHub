# FoodHub

FoodHub is an evolution of the educational Foodgram project.

The goal of this project is to transform the original recipe-sharing application into a modern platform with enhanced functionality, multilingual support, and AI-powered features.

## Planned Features

The project roadmap includes:

- 🌍 Multilingual interface (Russian / English)
- ⭐ Recipe rating system (0–5 stars)
- 💬 Reviews and comments
- 🔍 Advanced recipe search and filtering
- ❤️ Improved favorites and recipe collections
- 👤 Extended user profiles
- 📊 Personal user statistics
- 🤖 AI-powered recipe recommendations and content generation
- 🚀 Performance improvements and API enhancements

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- React
- Docker
- Nginx
- GitHub Actions

## Project Status

🚧 The project is currently under active development.

FoodHub started as an educational project and is being transformed into an independent application with new functionality and continuous improvements.
