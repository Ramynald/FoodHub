# 🍳 FoodHub

FoodHub — современная платформа для публикации, поиска и хранения рецептов.

Проект основан на учебном проекте **Foodgram**, но развивается как самостоятельный продукт с новыми возможностями и собственной концепцией.

---

## ✨ Текущие возможности

На данный момент проект позволяет:

- регистрацию и авторизацию пользователей;
- публикацию рецептов;
- добавление рецептов в избранное;
- создание списка покупок;
- работу с ингредиентами и тегами;
- загрузку изображений;
- использование REST API.

---

## 🚀 Запуск проекта

### Требования

- Docker
- Docker Compose

### Клонирование репозитория

```bash
git clone https://github.com/Ramynald/FoodHub.git
cd FoodHub
```

### Создание файла `.env`

Создайте файл `.env` и заполните необходимые переменные окружения.

### Запуск

```bash
docker compose up --build
```

После запуска будут доступны:

- Frontend — http://localhost/
- API — http://localhost/api/
- Панель администратора — http://localhost/admin/
